# hotelsgardnershills

Sitio web de **Gardners Hills**, hotel de cabañas en Villanueva, La Guajira (Colombia).

## Stack

Next.js 15 · React 19 · TypeScript · Tailwind CSS 4 · GSAP + ScrollTrigger · Lenis

## Desarrollo

```bash
npm install
npm run dev   # http://localhost:5206
```

## Estructura

- `app/` — layout, página principal, sitemap y robots
- `components/` — secciones, navegación, reservas, galería y UI
- `data/` — contenido editable (contacto, cabañas, servicios, actividades, galería)
- `public/` — logo, video del hero e imágenes

Los pendientes de contenido y recursos están en `PENDIENTES.md`; la auditoría inicial, en `AUDITORIA-FASE-1.md`.
